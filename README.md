# Student Performance Analyzer

A beginner-friendly Python and NumPy mini project that analyzes student marks and generates a class performance summary.

## Features

* Accepts student names and marks
* Stores marks using a NumPy array
* Displays student names and marks
* Finds highest and lowest marks
* Calculates average and total class marks
* Displays students scoring above the class average
* Generates a fail list for students scoring below 40
* Adds grace marks using NumPy broadcasting
* Sorts marks in ascending and descending order
* Identifies the topper
* Displays the number of pass and fail students

## Technologies Used

* Python
* NumPy
* Jupyter Notebook

## Purpose

This project was created to practice NumPy arrays, array operations, loops, conditions, broadcasting, and basic data analysis.
